## 📌 Overview

This repository documents an enterprise-grade Linux infrastructure deployment and administration project.

It covers Linux server deployment, network configuration, enterprise storage, security hardening, production validation, monitoring and automation.

The objective is to build a complete real-world infrastructure administration reference from deployment to production operations.

---

## 🏗️ Infrastructure Scope

The project covers:

- Linux Server Deployment
- VMware Virtual Infrastructure
- Network Configuration
- SAN Storage
- iSCSI
- LVM
- SSH Security
- Firewall
- SELinux
- User Management
- Production Go-Live
- Health Checks
- Monitoring
- Backup Validation
- Bash Automation
